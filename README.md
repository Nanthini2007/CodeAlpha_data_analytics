# TASK 2: Global YouTube Statistics - Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Global YouTube Statistics dataset. The aim is to understand the data structure, identify trends, detect anomalies, and generate insights using statistical analysis and visualization.

---

## 🎯 Objectives
- Explore dataset structure and variables
- Identify missing values and duplicates
- Analyze trends and patterns
- Detect outliers and anomalies
- Validate assumptions using statistics
- Generate meaningful business insights

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
Global YouTube Statistics Dataset

Key columns:
- Youtuber
- Subscribers
- Video Views
- Uploads
- Category
- Country
- Earnings
- Channel Type

---

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Duplicate Check
- Statistical Summary
- Outlier Detection

---

## 📈 Visualizations Created
- Top 10 Channels by Subscribers
- Country-wise Channel Distribution
- Category Analysis
- Subscribers vs Views
- Boxplot for Outliers

---

## 🔍 Key Insights
- Subscriber count and views show strong correlation.
- Some channels behave as outliers.
- Few countries dominate creator count.
- Certain categories have higher popularity.

---

## 📌 Conclusion
EDA helped transform raw YouTube data into meaningful insights by identifying trends, relationships, and anomalies.



# TASK 3: Netflix Data Visualization Project

## 📌 Project Overview
This project focuses on analyzing Netflix Titles dataset using visualization techniques to understand content distribution, trends, and viewing-related insights.

---

## 🎯 Objectives
- Explore Netflix dataset
- Clean and preprocess data
- Create meaningful charts and graphs
- Identify content trends
- Generate business insights

---

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
Netflix Titles Dataset

Key columns:
- Show ID
- Type
- Title
- Country
- Release Year
- Rating
- Duration
- Genre

---

## 📊 Visualizations Created
- Movies vs TV Shows Distribution
- Top 10 Countries Producing Content
- Release Year Trend
- Rating Distribution
- Genre Distribution
- Duration Analysis

---

## 🔍 Key Insights
- Movies dominate Netflix more than TV Shows.
- Some countries contribute major content.
- Content growth increased over years.
- Certain ratings are more frequent.
- Drama and International genres are common.

---

## 📌 Conclusion
Data visualization helped convert raw Netflix data into understandable insights, supporting better understanding of Netflix content trends.
