# TASK 2: Global YouTube Statistics - Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Global YouTube Statistics dataset. The aim is to understand the data structure, identify trends, detect anomalies, and generate insights using statistical analysis and visualization.

---

## 🎯 Objectives
- Explore dataset structure and variables
- Identify missing values and duplicates
- Analyze trends and patterns
- Detect outliers and anomalies
- Validate assumptions using statistics
- Generate meaningful business insights

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset
Global YouTube Statistics Dataset

Key columns:
- Youtuber
- Subscribers
- Video Views
- Uploads
- Category
- Country
- Earnings
- Channel Type

---

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Duplicate Check
- Statistical Summary
- Outlier Detection

---

## 📈 Visualizations Created
- Top 10 Channels by Subscribers
- Country-wise Channel Distribution
- Category Analysis
- Subscribers vs Views
- Boxplot for Outliers

---

## 🔍 Key Insights
- Subscriber count and views show strong correlation.
- Some channels behave as outliers.
- Few countries dominate creator count.
- Certain categories have higher popularity.

---

## 📌 Conclusion
EDA helped transform raw YouTube data into meaningful insights by identifying trends, relationships, and anomalies.
